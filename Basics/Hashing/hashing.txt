Hashing is a technique used to store and retrieve data quickly using a key. It maps a key to an index in a data structure called a hash table, allowing operations in O(1) average time.

Why Hashing?
    Fast searching
    Fast insertion
    Fast deletion
    Used for frequency counting and lookups

Example

Suppose we have an array:

    arr = {1, 2, 1, 3, 2, 1}

To count frequencies:

    1 → 3
    2 → 2
    3 → 1

Instead of checking every element repeatedly (O(n²)), 
hashing stores the count and gives the answer in O(n).
